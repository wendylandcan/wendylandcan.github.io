关于我

为什么转行做 AI

大家好！我是曹嘉璇，一个超典型的 ENFP，也是个学了七年法的小镇做题家。快毕业时，我做了个决定，All in AI。

以前有个点子，光是不会写代码、不会做设计，就可能卡住了。现在，一个人借助 AI 就能先做出个样子，拿给别人看。让我兴奋的是，人人都有机会用上这种以前很难想象的创造力和表达力。我觉得这会改变很多事，也想亲自下场，边做边看，和别人一起做点有用的东西。

我相信，这会是一场人本主义的文艺复兴。能做的事多了，我更想问问自己，什么问题值得解决，想过怎样的日子，又想和谁一起创造？

我相信，相比于 build in public，更应该 build for the public。我最想做的产品，是让人在 AI 时代更容易找到彼此，也更愿意听对方把话说完。如果你也对这件事好奇，欢迎线下来捉！

企业 AI

AI 产品经理实习

蔚来法务 AI 平台

在一个地方问法务、查资料，也能和同事一起跟进案件。

项目详情 · 蔚来法务 AI 平台
为什么做
同事有法务问题时，要在不同渠道找人。问过的问题也很难留下来，下次遇到还得再问。
我做了什么
我参与搭建平台，负责咨询、案件、律所、知识和资讯模块的设计。咨询 Agent 可以在飞书里查知识库、回答问题，需要时把咨询转给法务，并留下处理记录。
怎么验
我和团队回看咨询案例，请法务抽检，重点看答案有没有依据、信息不够时有没有追问。我们也整理样本做复测，看看改完有没有好一些。

劳动法咨询

产品负责人

职引 Pilot

给劳动者、用工单位和律师做的咨询工具。它会先问清情况，再给分析和出处。

项目详情 · 职引 Pilot
为什么做
合同签没签、什么时候离职、在哪里工作，漏问一个细节，劳动法问题的答案就可能变了。
我做了什么
我梳理了 24 个咨询场景，设计 Agent 先判断是哪类问题，发现事实不齐就继续问，再给法律分析。劳动者、用工单位和律师会收到各自需要的报告。法条和案例通过 MCP 查北大法宝，赔偿金额交给规则计算器。
结果
我们在 iCourt 第二届全国法律人 AI 应用大赛律所赛道拿到第二名。这个赛道有 173 支队伍。

独立作品

独立设计与实现

理清爱

朋友说「来评评理」，我就做了个双人线上法庭，让两个人都有机会把话说完。

项目详情 · 理清爱
为什么做
吵完架去问 AI「谁对谁错」，它听到的通常只有一个人的版本。我想让另一方也有地方讲自己的感受，补上遗漏的细节。
我做了什么
我借了法庭的流程，两个人可以各自陈述、发截图和录音，也可以回应对方。两边实时同步，最后由 AI 写一份「判决书」。
结果
我把不同任务交给大小模型分别处理，能复用的结果就缓存起来。复杂案件的单次 API 成本降了六成以上。
60%+复杂案件单次 API 成本降幅

工作流自动化

法务 AI 产品实习

订单喵

在莉莉丝实习时，我用 Dify 做了个小工具，帮同事核对订单。

项目详情 · 订单喵
为什么做
审订单时，法务得在 OA 和 Excel 之间反复核对。看得多了，细节容易漏掉。
我做了什么
我把同事平时会看的要点和常见风险写成规则，让工作流去找信息、做比对，再把值得留意的地方标出来。
结果
同事少做了一些重复核对，小工具后来也拿到了公司的 AI 提效大赛创新奖。

一个还在想的点子

独旅同行

我挺喜欢一个人旅行。只是到了饭点，有时也想找个人一起多点两道菜，吃完再各走各的。我就在想，这样的碰面能不能容易一点？

我做了个小原型，想试试能不能用 AI 帮独旅的人约顿饭，或者找个搭子走一小段。AI 可以帮忙理清大家想去哪儿、吃什么，再说说彼此哪里合拍、哪些事可以先聊。见不见面，由两个人自己决定。

我想找对这件事有共鸣的人一起琢磨。如果你也有过这样的旅行时刻，或者想一起试试这个点子，来找我聊聊。
